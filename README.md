# Финансы

Личное PWA для учёта денег на iPhone: быстрый ввод трат, счета в RUB/USD/EUR, конверты с переносом остатка,
правило 50/30/20 на месяц, распределение каждого поступления, цели на реальных счетах, экспорт в Excel.

Данные хранятся только на устройстве (IndexedDB). Сервера нет; на GitHub Pages лежит только код.

## Разработка

```bash
npm install
npm run dev        # http://localhost:5173
npx vitest run     # тесты логики, бэкапа и курсов
```

Публикация — автоматически при пуше в `main` (GitHub Actions → Pages).

## Устройство

- `src/domain/calc.ts` — балансы, конверты, 50/30/20, распределение поступлений, цели
- `src/domain/excel.ts` — экспорт/импорт Excel (скрытый лист `_backup` содержит полную копию данных)
- `src/domain/rates.ts` — курсы ЦБ (cbr-xml-daily.ru), кэш и офлайн-фолбэк
- `src/lock.ts` — замок: PIN (PBKDF2) + Face ID через passkey
- `src/ui/*` — экраны
