# Working in finance

After completing a user-requested code change in this repository, run the relevant checks, review the diff, then commit only the files changed for that task and push the commit to GitHub without waiting for a separate publish request.

Push the current branch to its branch of the same name on `origin`. For work on `main`, push to `origin/main`. Before pushing, fetch and confirm the remote branch has not advanced; if it has, integrate the remote changes safely first. Never force-push or overwrite remote history.

Do not include pre-existing or unrelated changes in the commit. If authentication, checks, conflicts, or repository rules prevent publication, preserve the work and explain what remains to be done. Publish completed, checked work rather than each intermediate file save.
